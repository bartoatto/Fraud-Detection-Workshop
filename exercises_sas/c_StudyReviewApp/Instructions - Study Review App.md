# Publish the Study Review Desk
The review app is the same for the SAS and Python versions. It reads the files the SAS programs wrote to the NetApp Volume (`adam/adsl.sas7bdat`, `tfl/t_dm1.csv`, and the compare results), so nothing needs to change.

Follow `exercises/c_StudyReviewApp/Instructions - Study Review App.md`. The only difference: make sure the three SAS jobs in Exercise B have finished first.

*Talk track:* a team can write its analysis programs in SAS and still give reviewers a modern web app. Apps are written in whatever language fits the audience.
